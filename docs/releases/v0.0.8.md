# RSVP Nano AMOLED v0.0.8

This release hardens the AMOLED OTA path and adds audio cues to Focus Timer.

## What's Changed

- Focus Timer now plays distinct audio cues when a timer starts, when warm-up/work/break phases complete, and when a timer is cancelled.
- Audio output now supports short generated tones instead of only one fixed beep.
- OTA release metadata is stricter: release tags must use the expected `v...` format, release asset URLs must match this repository and tag, and OTA redirects are limited to GitHub's release asset CDN.
- AMOLED OTA remains locked to `darkbringer1/rsvpnano` and `rsvp-nano-amoled-ota.bin`.

## Assets

- `rsvp-nano-amoled.bin` is the full browser-flasher image for fresh installs.
- `rsvp-nano-amoled-ota.bin` is the app-only binary used by OTA updates.
