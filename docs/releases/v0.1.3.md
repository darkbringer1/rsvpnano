# RSVP Nano AMOLED v0.1.3

Architecture and hardening release. This keeps the user-facing reader behavior
close to v0.1.2 while making the firmware easier to maintain and less fragile
around OTA, standby, clock, book-library, and developer flashing workflows.

## What's Changed

### App architecture
- `App.cpp` has been reduced by moving separable domains into focused modules.
- Extracted `StandbyScreensaver` for Life, Maze, Voronoi, and screen-off standby
  rendering.
- Extracted `TextEntryController` for on-device text entry screens.
- Extracted `ClockController` for RTC, local time, timezone labels, and network
  clock sync helpers.
- Extracted `OtaController` for background update checks, update blocking, and
  firmware-update execution.
- Extracted `TimeEstimateEngine` for reading-time cache rebuilds and remaining
  time estimates.
- Extracted `BookLibraryStore` for per-book persistence and library metadata.

### Reliability
- Fixed a PMU power-key interrupt race by avoiding idle clears of AXP2101 key
  IRQ state. This prevents a narrow case where a wake tap could be latched and
  then erased before the app handled it.
- Kept the highest-risk coordinator paths in `App`: power/wake handling,
  reader input/rendering, and menu routing remain central because they are still
  tightly coupled to the app state machine.

### Developer workflow
- `make menu` now opens a clearer grouped dev console with status, workflow,
  maintenance, and settings sections.
- `make monitor` rescans live serial ports immediately instead of relying on a
  stale cached port.
- Serial monitor selection is compatible with macOS Bash 3.2.
- Most menu choices now use single-key input; text fields such as version labels
  still use normal Enter-based input.

## Notes

This is mostly an internal cleanup and hardening release. The biggest practical
benefits are lower future-change risk, more isolated OTA/clock/book/time-estimate
code, and a more reliable local flash/monitor loop.

## Assets

- `rsvp-nano-amoled.bin` is the full browser-flasher image for fresh installs.
- `rsvp-nano-amoled-ota.bin` is the app-only binary used by OTA updates.
