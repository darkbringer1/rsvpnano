# RSVP Nano AMOLED v0.1.0

This release makes the power button work properly, adds a real-time clock with
reading stats and streaks, and finishes books with a summary.

## What's Changed

### Reading
- Finishing a book now shows a completion summary — title, words read, your
  average reading speed, and time spent — then takes you to the library.
  Finished books are marked "Read"; re-opening one restarts it from the start.
- New "Reading stats" screen with lifetime totals: words read, time read,
  books finished, and average speed.
- Reading streak: counts consecutive days you read, shown on the stats screen.

### Power button
- The PWR button now powers the device off: hold it to shut down (a quick tap
  does nothing, so no accidental power-offs). Power back on by holding PWR.
- Power-off is now a true shutdown via the power-management chip instead of a
  sleep that woke itself back up.
- The "Power off" menu item now asks for confirmation instead of blanking the
  screen instantly.

### Clock (new)
- The device now keeps real time using its built-in clock.
- Settings > Clock: set the time over Wi-Fi (also auto-detects your timezone),
  adjust the timezone manually, or set the date and time by hand.

### Navigation
- Swipe right in any menu to go back a level instead of scrolling up to "Back".

## Assets

- `rsvp-nano-amoled.bin` is the full browser-flasher image for fresh installs.
- `rsvp-nano-amoled-ota.bin` is the app-only binary used by OTA updates.
