# RSVP Nano AMOLED v0.0.9

This release fixes a touch input failure that required a reboot to recover.

## What's Changed

- Fixed the touchscreen becoming permanently unresponsive after the screen turned off (sleep or screensaver). The touch driver previously disabled itself after a short burst of I2C read failures — which the panel power transition could trigger — and only re-enabled on boot, so wake-on-touch deadlocked and only a restart recovered it.
- The touch driver now self-heals: on repeated read failures it restarts the I2C bus and re-probes the controller, then keeps polling instead of giving up until the next reboot.

## Assets

- `rsvp-nano-amoled.bin` is the full browser-flasher image for fresh installs.
- `rsvp-nano-amoled-ota.bin` is the app-only binary used by OTA updates.
